# JasonSI

En este proyecto se trabajó con el lenguaje de agentes Jason. El objetivo fue desarrollar a los agentes para que cumpliesen una serie de funciones según eventos, momentos temporales o peticiones.

Este proyecto fue realizado en la asignatura de Sistemas Inteligentes del grado de Ingeniería Informática en la Escola Superior de Enxeñaría Informática, perteneciente a la UVigo.
